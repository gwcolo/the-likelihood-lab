# The Likelihood Lab

[![CI](https://github.com/gwcolo/the-likelihood-lab/actions/workflows/ci.yml/badge.svg)](https://github.com/gwcolo/the-likelihood-lab/actions/workflows/ci.yml)

An interactive, single-page teaching demo for maximum likelihood estimation.
Pick a distribution, see a dataset, and drag the parameter sliders to fit the
probability density function over the data — the log-likelihood readout and
per-parameter trace plots show how good your fit is and how your attempts
stack up. A reveal button marks the true (empirical) MLE so you can compare
your best manual fit to the answer.

The teaching point: MLE is not an algebra exercise — it is finding the
parameter values that make the observed data most probable, which you can
*see* as fitting the shape of the PDF over the data. Some datasets are
deliberately mismatched to their distribution (bimodal data under a Normal,
for example), because real data never comes with its true distribution
attached — the distribution is a modeling choice.

## Running it

Everything is client-side HTML + JavaScript with no dependencies and no build
step. Open `index.html` in a browser, or serve the directory with any static
file server:

```
python -m http.server
```

Live at https://gwcolo.github.io/the-likelihood-lab/

## Testing and deployment

Every push runs two test suites on GitHub Actions. A headless browser
self-test (`tools/run-selftest.sh`) loads the page in Chrome and checks 29
interactions across all six tabs, including sliders, attempt logging and the
reveal and challenge states. Math tests (`tools/test-math.js`) check every
dataset's revealed MLE: closed forms are recomputed independently, and every
answer is confirmed to be a maximum of the log-likelihood. Pushes to `main`
deploy to GitHub Pages only if both pass, so a failing test leaves the live
site on its last good version. Everything is defined in
`.github/workflows/ci.yml`.

## Structure

- `index.html` — the page
- `css/style.css` — styling
- `js/distributions.js` — math layer: PDFs, log-likelihoods, empirical MLE
- `js/gp.js` — Gaussian Process math layer: RBF kernel, log marginal likelihood, posterior
- `js/datasets.js` — curated, labeled teaching datasets (generated by `tools/generate-datasets.js`)
- `js/app.js` — UI layer: SVG rendering, sliders, attempt tracking
- `tools/run-selftest.sh`, `tools/selftest.js` — headless browser self-test
- `tools/test-math.js` — math-correctness tests (Node, no browser)
- `tools/generate-datasets.js`, `tools/generate-reference.js` — dataset and reference-document generators
- `.github/workflows/ci.yml` — CI/CD: self-test on every push, Pages deploy from `main`
- `LICENSE` — MIT

## Local Development

(committed). Machine-specific settings — anything containing an absolute local
path, such as `additionalDirectories` — belong in `.claude/settings.local.json`,
